# Das System speichert keine Inhalte

Agenten (etwa der Grok-Bot) liefern bei jedem Aufruf den vollständigen Inhalt eines Produkts, bei der Tagesübersicht einschließlich der Routinen. Dieses System besitzt die Gestaltung, nicht die Inhalte: Es speichert keine Routinen, Wochenpläne oder Personen. Einzige Ausnahme ist die erzeugte Datei, die 24 Stunden unter einem nicht erratbaren Link abrufbar bleibt.
