# Kura ist eine Datei im Repository

Kura steht in `src/lib/kura/kura.json`. Die Werkbank verändert nur eine Arbeitskopie im Browser; wirksam wird eine Änderung erst durch einen Commit. Ein Speicher bei Cloudflare hätte Änderungen sofort auf allen Geräten wirksam gemacht, aber ohne Versionsstand und ohne Testlauf über alle Produkte. Das Hausdesign ändert sich selten, deshalb zählt Nachvollziehbarkeit mehr als Geschwindigkeit.
